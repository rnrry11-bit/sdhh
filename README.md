# 프로포즈 대작전

학생 기기에서 단어 카드를 이어 붙여 프로포즈 문장을 만들고, 접속 순서대로 받은 조 번호로 무작위 다른 조에게 보내는 학급 활동이에요. 학생은 로그인 없이 주소만 열면 되고, 선생님은 `/teacher`에서 비밀번호로 들어와 모든 문장을 실시간으로 봐요.

- 학생 화면: `https://내주소.onrender.com/`
- 교사 화면: `https://내주소.onrender.com/teacher`

## Render 무료 호스팅에 올리는 방법

화면 이름은 서비스가 바뀌면 조금 달라질 수 있어요.

### 1. GitHub에 파일 올리기
1. github.com에서 가입하고 **New repository**로 새 저장소를 만들어요. 이름은 아무거나 괜찮아요. (공개/비공개 모두 가능)
2. 저장소 화면의 **Add file → Upload files**에서 이 폴더 안의 파일을 전부 끌어다 놓고 **Commit changes**를 눌러요.
   - 올려야 할 것: `server.js`, `package.json`, `deck.json`, `render.yaml`, `public` 폴더(안의 파일 6개)
   - `public` 폴더째 끌어다 놓으면 폴더 구조가 유지돼요.

### 2. Render에서 서비스 만들기
1. render.com에 가입하고 GitHub 계정을 연결해요.
2. **New → Web Service**에서 방금 만든 저장소를 골라요.
3. 아래처럼 입력해요.
   - Runtime: **Node**
   - Build Command: `npm install` (비워 둬도 돼요)
   - Start Command: `npm start`
   - Instance Type: **Free**
4. **Environment Variables**에서 `TEACHER_PIN` 을 추가하고 값에 교사 비밀번호를 적어요. 안 적으면 `0000` 이 돼요.
5. **Deploy**를 누르고 몇 분 기다리면 `https://이름.onrender.com` 주소가 생겨요.

(저장소의 `render.yaml`을 쓰는 **Blueprint** 방식으로 만들어도 같은 설정이 적용돼요. 이때도 `TEACHER_PIN` 값은 직접 넣어야 해요.)

## 이미 올려 둔 서비스를 새 버전으로 바꾸는 방법

이번 버전에서 바뀐 파일은 6개예요: `server.js`, `README.md`, `public/common.js`, `public/student.js`, `public/teacher.js`, `public/style.css`.

1. 압축을 풀고, GitHub 저장소에서 **Add file → Upload files**를 눌러요.
2. 바뀐 파일 6개를 **같은 이름, 같은 위치**로 끌어다 놓아요. `public` 안의 파일 4개는 저장소의 `public` 폴더 안에 올라가야 해요. 같은 이름이면 덮어써져요.
3. **Commit changes**를 누르면 Render가 자동으로 다시 배포해요. 1~3분 걸려요. 이때 서버가 다시 켜지니 조 번호와 제출 기록은 초기화돼요.

## 수업 전 꼭 알아 둘 점

- 무료 서버는 15분 동안 접속이 없으면 꺼져요. 꺼진 뒤 첫 접속은 깨우는 데 약 1분이 걸려요. **수업 시작 5분 전에 `/teacher`를 한 번 열어 두세요.** 화면이 열려 있는 동안은 4분마다 자동으로 신호를 보내 서버가 꺼지지 않게 해요.
- 서버를 다시 켜면 조 번호, 제출 기록, 교사 화면에서 고친 카드가 모두 처음 상태로 돌아가요. 수업 중에 서버가 꺼졌다면 학생들이 화면을 새로고침하면 새 조 번호를 받아요.
- 고친 카드를 계속 쓰고 싶다면 교사 화면의 **카드 전체 내려받기**로 `deck.json`을 받아서 GitHub의 `deck.json`을 그 파일로 바꿔 주세요. 바꾸면 Render가 자동으로 다시 배포해요.
- 다음 수업 전에는 교사 화면의 **새 활동 시작**을 눌러 조 번호를 처음부터 다시 받게 해 주세요.

## 동작 규칙

- 조 번호는 학생 기기가 처음 접속한 순서대로 1조, 2조, … 로 정해져요. 새로고침해도 같은 조예요.
- 제출하면 **지금 화면이 열려 있는 다른 조** 중 한 곳으로 가요. 받은 프로포즈가 가장 적은 조를 먼저 고르고, 후보가 여럿이면 무작위로 정해서 모든 조가 골고루 받아요. 다른 조가 없으면 보낼 수 없어요.
- 프로포즈를 받은 조는 **수락/거절**을 고르고, 이유(적지 않아도 돼요)와 점수를 남겨요. 점수는 참신성 0~5점 + 진심이 느껴지는지 0~5점이고 합계 10점 만점이에요. 한 번 보낸 답장은 고칠 수 없어요.
- 교사 화면에는 수락·거절 수, 조별 평균 점수, 모든 문장과 답장 내용이 실시간으로 보여요. **결과 복사**에도 답장 내용이 들어가요.
- 학생은 글자를 직접 입력할 수 없고 선생님이 검수한 카드로만 문장을 만들 수 있어요. 서버도 카드 목록에 없는 말은 받지 않아요.
- 교사 화면의 카드 검수 탭에서 카드 글자 수정, 숨기기(체크 해제), 추가, 삭제를 할 수 있어요.

## 내 컴퓨터에서 시험해 보기 (선택)

Node.js 18 이상이 있으면 이 폴더에서 아래 명령으로 실행해요.

```
TEACHER_PIN=1234 node server.js
```

브라우저에서 `http://localhost:3000` (학생), `http://localhost:3000/teacher` (교사)를 열어요. 시험할 때 학생 화면을 여러 개 열려면 시크릿 창을 쓰면 돼요. 같은 브라우저는 같은 조로 인식돼요.
